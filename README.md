# Woo Bulk Product Importer

Enterprise-grade WooCommerce JSON product synchronization plugin.

## Installation and use

Place the `woo-bulk-product-importer` directory in `wp-content/plugins/` and activate **Woo Bulk Product Importer** from the WordPress Plugins screen.

This is the current JSON synchronization plugin for WooCommerce. Install only one version of Woo Bulk Product Importer per site.
